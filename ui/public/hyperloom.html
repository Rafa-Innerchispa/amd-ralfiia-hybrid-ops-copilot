Hyperloom on Radeon AI PRO R9700

Experimental RDNA4 compatibility work for AMD Hyperloom. The R9700 runs ROCm 10 and local vLLM today, but current Hyperloom releases expose official runner types for Instinct GPUs. This project adds a truthful R9700 compatibility path instead of pretending the card is an MI300X.
